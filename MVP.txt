TribalMMO

Minimum Viable Product (MVP) Specification

A lightweight, functional foundation of the game that includes core loops, basic systems, and essential player interactions. This MVP is designed to be fully playable, expandable, and stable while avoiding unnecessary complexity.

1. Core MVP Goals

- Deliver a playable tribal-era RPG with text-driven mechanics.
- Enable player-run clans and basic settlement building.
- Provide infinite progression through 4 core stats (Level 1-100 skills).
- Implement tap-forward exploration with random RNG events.
- Support clan system with roles and founding.
- Ensure the game is stable, scalable, and content-light.

2. MVP Features Overview

Included

- Account creation and character creation
- Exploration system with RNG events
- Timed action system
- Basic combat
- 4 Core Stats: Strength, Defence, Speed, Vitality (infinitely scaling)
- 5 Skills (Level 1-100): Gathering, Crafting, Combat, Woodcutting, Mining
- Player Level (meta-level from total skill progression)
- Clan creation and membership with roles
- Basic settlement system (Tier I buildings)
- Basic crafting and gathering
- Pets (passive stat bonuses)
- Player marketplace (basic listings)
- Auction house

Not Included (Post-MVP)

- Advanced settlement tiers (II-III)
- Diplomacy systems (alliances, wars)
- Seasonal events
- Spirit phenomena
- Ruins and advanced zones
- Complex crafting quality tiers
- Clan wars and raids
- Territory control
- Mounts

3. Player Systems

3.1 Character Creation

- Name
- Background (cosmetic only)

3.2 Core Stats (Infinitely Scaling)

- Strength — physical power
- Defence — resilience
- Speed — agility
- Vitality — health

Stats grow through training but cost energy.

3.3 Skills (Level 1-100)

- Gathering
- Crafting
- Combat
- Woodcutting
- Mining

3.4 Player Level

Meta-level calculated from total skill progression. Used for matchmaking and unlocks.

4. Exploration System (Core MVP Loop)

4.1 Tap-Forward Exploration

Players click "Take a Step" to move through zones:
- Forest
- Plains
- Riverbank

4.2 Random Events (Weighted RNG)

Each step may trigger:
- Resource finds (wood, herbs, stone)
- Wildlife encounters (boar, wolf, bear)
- Spirit phenomena (rare, gold rewards)
- Random text events ("you tripped over a stone")
- Gold finds (1-5 gold coins)
- Random item finds (herbs, wood, stone)

4.3 Stamina

- 100 maximum
- Regenerates over time (1 per 3 minutes)
- Costs 5 stamina per exploration step

5. Timed Action System

5.1 Action Types

- Crafting
- Training
- Gathering (bulk)
- Building (settlement)

5.2 Durations

- 5 minutes
- 15 minutes
- 1 hour
- 4 hours

5.3 Action Slots

- 1 slot at start
- 2 slots unlocked at higher skill levels

6. Combat System

6.1 Combat Type

- Turn-based
- Text-driven
- Deterministic with light randomness

6.2 Combat Encounters

- Wild animals (boar, wolf, bear, serpent)
- Rival scouts
- Stone golem (rare, high difficulty)

6.3 Player Stats Used

- Strength (ATK)
- Defence (DEF)
- Speed (flee chance)
- Vitality (HP)

6.4 Equipment

- Basic weapons (attack bonus)
- Basic armour (defence bonus)

7. Clans (Player-Run)

7.1 Founding Requirements

- 10 gold (beta price, will be 5,000 at launch)
- Name and description
- Philosophy selection

7.2 Clan Features (MVP)

- Name
- Description
- Philosophy (Warborn, Earthkeepers, Pathfinders)
- Member list with roles
- Clan chat

7.3 Clan Roles

- Chieftain (leader)
- Elder (senior)
- Hunter (combat specialist)
- Gatherer (resource specialist)
- Crafter (crafting specialist)
- Member (standard)

7.4 Clan Philosophies

- Warborn: +2 STR, +1 ATK
- Earthkeepers: +2 VIT, +1 DEF
- Pathfinders: +2 SPD, +1 ATK

8. Settlement System

8.1 Settlement Buildings (Tier I Only)

- Longhouse (clan HQ)
- Workshop (crafting speed +5%)
- Garden (herb yield +5%)
- Storage Pit (resource cap +500)

8.2 Building Requirements

Each building requires:
- Wood
- Stone
- Time (timed action)
- Member contributions

8.3 Settlement Bonuses

Applied to all clan members.

9. Crafting & Gathering

9.1 Resources

- Wood, Stone, Herbs, Hides
- Bone, Clay, Copper, Tin

9.2 Crafting Recipes (MVP)

- Basic tools (Stone Axe, Wooden Spear)
- Basic weapons (Bone Knife, Bow)
- Basic armour (Hide Armor, Reinforced Armor)
- Simple potions (Herb Poultice)

9.3 Gathering Methods

- Exploration finds
- Dedicated woodcutting (Normal Tree, Oak Tree, etc.)
- Dedicated mining (Copper Vein, Iron Vein, etc.)

10. Pets (Optional Buffs)

10.1 Pet Types

- Wolf: +2 STR, +1 SPD
- Cat: +2 SPD, +1 VIT
- Hawk: +3 SPD
- Boar: +3 VIT, +1 DEF
- Dog: +1 STR, +2 VIT

10.2 Pet System

- One pet slot
- No leveling
- No combat
- Passive stat bonuses only

11. Marketplace

11.1 Basic Features

- List items
- Buy items
- Simple tax (5%)

11.2 Auction House

- Timed auctions
- Bidding system

15. Summary

This MVP provides a fully functional tribal-era RPG with infinite stat progression, finite skill leveling, exploration with random events, clan-based social structure, and a player-driven economy. It is intentionally minimal, stable, and expandable, forming the foundation for TribalMMO's long-term development.
